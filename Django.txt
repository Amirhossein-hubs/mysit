# HTTP method

http: یک پروتوکل ارتباطی امن نیست

http: HTTP یک زبان مکالمه یا مجموعه‌ای از قوانین است که بر اساس آن مرورگر شما (کلاینت) و سروری که جنگو روی آن اجرا می‌شود (سرور) با هم صحبت می‌کنند.

post:غلب برای ایجاد ساخت منابع جدید استفاده می‌شود. به طور خاص‌، برای ایجاد منابع تابع استفاده می‌شود

get:برای خواندن (یا بازیابی) نمایش یک منبع استفاده می‌شود
get:میشه اطلاعات رو هم باهاش جابه جا کرد که یکسری محدودیتها دارد

put/patch:برای تغییر و یا تصحیح اطلاعات مورد استفاده قرار می‌گیرند

delet:منحصرا از این متد برای حذف یک داده در پایگاه داده‌ها مورد استفاده قرار می‌گیرد.


#status codes

< 1xx >
informational responses     اطلاع رسانی
پاسخ ابتدایی به یم درخواست

< 2xx >
successful responses        موفقیت
درخواست شما باموفقیت پردازش شده

< 3xx >
Redirection responses       انتقال
این کدها نشان‌دهنده نیاز به انتقال یا ارجاع به یک URL دیگر هستند

< 4xx >
client error responses      خطای کلاینت
این کدها نشان‌دهنده خطاهایی هستند که به دلیل درخواست نادرست کلاینت بوجود آمده‌اند.
درخواست نادرست کاربر ایجاد میکنه

< 5xx >
server error responses      خطای سرور
این کدها نشان‌دهنده مشکلاتی هستند که در سرور اتفاق افتاده و باعث شده‌اند که درخواست به درستی پردازش نشود.
مشکلات سمت سرور را نمایش میدهد

##template tag                  {%  %}
عملکردی را مثل یک تابع برای کاری انجام می‌دهد

Display Logic. E.g., {% if %}...{% endif %}
Loop Control. E.g., {% for x in y %}...{% endfor %}
Block Declaration. E.g., {% block content %}...{% endblock %}
Content Import. E.g., {% include "header.html" %}
Inheritance. E.g., {% extends "base.html" %}



##template variable             {{  }}
این متغیرها در زمان اجرای صفحات می‌توانند به آن ارجاع داده شده و المان‌هایی را به نمایش بگذارند که به‌صورت داینامیک در صفحه قرار می‌گیرند.
Simple Variables. E.g., {{ title }}
Object Attributes. E.g., {{ page.title }}
Dictionary Lookups. E.g., {{ dict.key }}
List Indexes. E.g., {{ list_items.0 }}
Method Calls. E.g., {{ var.upper }}, {{ mydict.pop }}



## filter   |
شما با استفاده از | فیلتر را به یک متغیر اعمال می‌کنید
Change Case. E.g., {{ name|title }} or {{ units|lower }}
Truncation. E.g., {{ post_content|truncatewords:50 }}
Date Formatting. E.g., {{ order_date|date:"D M Y" }}
List Slicing. E.g., {{ list_items|slice:":3" }}
Default Values. E.g., {{ item_total|default:"nil" }}
